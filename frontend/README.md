# Sesh@ Frontend (Vercel Hobby Deployment)

A responsive Next.js workspace web application for note-taking, checklists, drawings, and Note Design Studio.

## Deployment on Vercel Hobby
1. Import your GitHub repository to Vercel.
2. Root Directory: `frontend` (or root if using single-repo Vite build).
3. Framework Preset: `Next.js`
4. Add the environment variables from `.env.example`.
5. Deploy.
6. Add your Vercel deployment URL to Google Cloud Console > APIs & Services > Credentials > Authorized JavaScript Origins.
